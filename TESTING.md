# Перевірка Ліхтаря перед релізом

Мета: пройти повний шлях користувача на «чистому» ПК, нічого не ризикуючи справжніми іграми.

## 0. Де перевіряти

Найкраще на Windows без Steam і без ваших інструментів розробника:
- **Windows Sandbox** (є в Windows Pro: «Компоненти Windows» → Windows Sandbox). Кожен запуск це чистий Windows. Усередині встановіть Python (потрібен лише для тестового сервера) або запускайте сервер на основному ПК і відкривайте в пісочниці адресу `http://ІР_ВАШОГО_ПК:8099/`.
- або друга обліковка Windows, або віртуальна машина.

## 1. Автоматичні перевірки (на ПК розробника, 2 хвилини)

```
cd lichtar\src-tauri
cargo test
cd ..\..\lichtar-catalog
python tools\validate_catalog.py catalog.json --release
```
`cargo test` перевіряє встановлення, відкат, відновлення після падіння, докачування, скасування. `validate_catalog` показує, що ще не заповнено в каталозі (до релізу він має виводити «Помилок: 0»).

## 2. Тестовий набір

З теки програми `lichtar`:
```
python tools\make_test_kit.py --out test-kit --big-mb 40
python tools\test_server.py test-kit\server
```
Сервер лишайте відкритим: у його вікні видно кожен запит і те, чи клієнт просив докачати. Для повільного завантаження: `--kbps 300`.

Підключення: Ліхтар → **Налаштування → Каталог → Адреса каталогу** `http://127.0.0.1:8099/catalog.json` → **Оновити**. З'явиться «Тестова гра».

## 3. Сценарії

| № | Що зробити | Як має бути |
|---|---|---|
| 1 | Запустити інсталятор `Lichtar_..._setup.exe` | SmartScreen: «Докладніше → Все одно запустити». Ставиться без прав адміністратора, є ярлик |
| 2 | Запустити Ліхтар | Заставка 4-5 с: англійські слова перетворюються на українські, потім головна |
| 3 | Підключити тестовий каталог (розділ 2) | Новина «Тестовий каталог підключено», у каталозі «Тестова гра» |
| 4 | Відкрити гру → «Вказати теку гри» → `test-kit\TestGame` | Кнопка стає «Встановити», під нею «Завантаження: 1 КБ». Невірна тека (без `TestGame.exe`) відхиляється повідомленням |
| 5 | «Встановити» | Прогрес, потім «Грати». Файл `data\lang.txt` має вміст `UKRAINIAN v1.0`, з'явився `data\extra.txt`. «Грати» відкриває Блокнот |
| 6 | У `test-kit\server` замінити `catalog.json` на `catalog-update.json`, у Ліхтарі «Оновити» в каталозі, потім «Оновити» на грі | `lang.txt` став `UKRAINIAN v1.1` |
| 7 | «Відкат до оригіналу» (двічі, з підтвердженням) | `lang.txt` знову `ORIGINAL`, `extra.txt` зник, кнопка «Встановити» |
| 8 | Після встановлення змінити `lang.txt` вручну й повернутись у вікно Ліхтаря | Кнопка «Відновити», пояснення про змінені файли. Після натиску файл відновлено |
| 9 | Заблокувати файл у PowerShell (див. нижче) і натиснути «Встановити» | Повідомлення «Файл «data/lang.txt» зайнятий. Закрийте гру й повторіть.» Гра не пошкоджена. Після Enter у PowerShell повтор проходить |
| 10 | Сервер з `--kbps 300`, каталог `catalog-big.json`, «Оновити» на грі, на ~30% «Скасувати» | «Скасовано. Завантажене збережено, можна продовжити.» Друга спроба в журналі сервера має `Range: bytes=...` і `206`, завантаження дозавантажується |
| 11 | У `catalog.json` змінити останній символ `sha256`, «Оновити» каталог, «Встановити» | «SHA256 не збігається...», файли гри не змінено |
| 12 | Зупинити сервер, «Оновити каталог зараз» | Програма працює, у налаштуваннях джерело «збережена копія» |
| 13 | Під час встановлення (великий патч) завершити Ліхтар у диспетчері завдань | При наступному запуску сповіщення «Гру повернено до початкового стану...», файли гри початкові |
| 14 | Масштаб Windows 100%, 125%, 150%; вікно мінімального розміру | Нічого не накладається, лінія таймлайну проходить через кружки, рамок навколо плиток немає |
| 15 | Світла й темна тема, «Вимкнути анімації» | Усі екрани читаються |

**Блокування файлу (сценарій 9).** У PowerShell:
```
$f = [System.IO.File]::Open("ШЛЯХ\test-kit\TestGame\data\lang.txt", 'Open', 'ReadWrite', 'None')
Read-Host "Файл заблоковано. Enter, щоб відпустити"; $f.Close()
```

## 4. Справжній патч (пробний)

1. Скопіюйте теку справжньої гри (не пробуйте на єдиній копії).
2. `python ..\lichtar-catalog\tools\inspect_game.py "ШЛЯХ\до\гри"`: отримаєте `exe`, назву теки, `appid`, збірку для запису в каталог.
3. Складіть zip: шляхи всередині архіву від кореня теки гри (щоб `Data/lang.txt` в архіві лягав у `<гра>\Data\lang.txt`).
4. Створіть Release з тегом `id-гри-v1.0` позначкою **pre-release** (каталог не зміниться), перевірте завантаження за посиланням.
5. Додайте дані в `lichtar-catalog\catalog.json`, виконайте там `python tools\validate_catalog.py catalog.json --release --online`, пройдіть сценарії 4-8 на справжній копії.
6. Для Steam-гри: перевірте відновлення після оновлення гри. Змініть `buildid` у `appmanifest` копії (або дочекайтесь справжнього оновлення), Ліхтар має показати «Відновити».

## 5. Що надсилати, якщо щось не так

Скриншот і журнал: **Підтримка → Скопіювати журнал**. Для збою встановлення зазначте, на якому сценарії це сталося.
