Українізатори ігор — в один клік

Безкоштовний лаунчер для українських локалізацій. Сам знаходить ваші ігри, ставить переклад і стежить за оновленнями.

Завантажити для Windows
Windows 10 / 11 · безкоштовно

Що вміє

  • Знаходить ігри сам. Steam, GOG та Epic Games, шукати теки вручну не треба.
  • Безпечне встановлення. Перед змінами робить копію, і гру завжди можна повернути до початкового стану.
  • Оновлення в один клік. Вийшла нова версія перекладу — Ліхтар скаже про це.
  • Новини про українізатори. Стрічка з нових релізів і подій навколо локалізацій.
  • Сам оновлюється. Нові версії програми підтягуються автоматично.

Якщо Windows показала «Windows захистила ваш ПК»

Це вікно SmartScreen. Воно з'являється для нових програм без платного сертифіката видавця, а не тому, що знайдено вірус. Щоб запустити інсталятор:
  1. Натисніть «Докладніше».
  2. Натисніть «Все одно виконати».
Ліхтар повністю відкритий: увесь код на GitHub, а кожен реліз збирається публічно в GitHub Actions. Файл можна перевірити самому.
